# CORREA3D — site institucional

Site estático responsivo para GitHub Pages. Não exige servidor próprio.

## Arquivos
- `index.html`: conteúdo e seções do site.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: menu mobile e envio do formulário para o WhatsApp.
- `assets/`: imagens usadas no site.
- `CNAME`: domínio personalizado pretendido (`correa3d.com`).

## Publicar no GitHub Pages
1. Envie todos os arquivos e a pasta `assets` para a raiz do repositório `correa3d`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `principal` e a pasta `/ (root)`, depois salve.
5. Aguarde a publicação. O GitHub mostrará o endereço temporário `https://<usuario>.github.io/correa3d/`.
6. Para usar `correa3d.com`, configure no painel do registrador os DNS indicados pelo GitHub Pages. A configuração exata depende de onde o domínio foi comprado.

## Formulário
O formulário abre uma conversa no WhatsApp comercial `+55 41 8439-7309` com os dados preenchidos. O visitante poderá anexar as fotos diretamente na conversa. Não há armazenamento automático de dados nem envio automático de e-mail.
